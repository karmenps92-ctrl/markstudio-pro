Conversión Inteligente en MarkStudio Pro: Puedes alternar entre los modos Normal, Discord y WhatsApp en el selector superior. Al hacer clic en "Convertir Sintaxis", tus negritas, tachados, encabezados y tablas se transformarán automáticamente respetando las reglas de la plataforma activa.

Elementos Básicos GFM

  • Negrita: **texto**
  • Cursiva: *texto* o _texto_
  • Tachado: ~~texto~~
  • Encabezados: # H1, ## H2, ### H3
  • Enlaces: [Texto](https://url.com)
  • Imágenes: ![Alt](https://imagen.png)
  • Cita: > Cita reflexiva
  • Separador: ---

Extensiones Avanzadas

  • KaTeX Matemáticas: $E=mc^2$ o $$\int x dx$$
  • Callouts GitHub: > [!NOTE], > [!TIP], > [!WARNING], > [!IMPORTANT]
  • Diagramas Mermaid: ```mermaid ... ```
  • Checklists Interactivas: - [ ] Pendiente y - [x] Hecho
  • Tablas Alineadas: | A | B | con :---:
  • Bloques con Copiado: ```js ... ```

Spoilers & Formato Discord

  • Spoilers Ocultos: ||texto confidencial|| (haz clic en la vista previa para revelarlo).
  • Subrayado: __texto subrayado__
  • Negrita Cursiva: ***texto destacado***
  • Encabezados: Soporta solo hasta nivel 3: # H1, ## H2, ### H3
  • Cita Multilínea: >>> texto que abarca todo el mensaje
  • Cita Simple: > texto de una línea

Resaltado & Trucos de Discord

  • Resaltado ANSI: ```ansi para texto coloreado por terminal.
  • Coloreado de Código: ```py, ```js, ```html, ```json
  • Timestamps Dinámicos: <t:1700000000:R> se adapta a la hora de cada miembro.
  • Menciones: @usuario, #canal, @everyone
  • Botón Copiar para Discord: En el menú exportar, copia directamente con formato listo para pegar en tu canal.

Sintaxis Nativa de WhatsApp

  • Negrita: *palabra* (¡Un solo asterisco!)
  • Cursiva: _palabra_ (Guiones bajos)
  • Tachado: ~palabra~ (Una sola tilde)
  • Monoespacio: ```código monoespaciado```
  • Citas: > Mensaje citado
  • Viñetas: - Elemento o * Elemento
  • Numeradas: 1. Primero, 2. Segundo

Limitaciones en WhatsApp

  • 🚫 Sin Encabezados: Los # se envían como caracteres literales. Nuestro conversor los traduce a *Negrita*.
  • 🚫 Sin Tablas: Las tablas se desarman en listas legibles con separadores •.
  • 🚫 Sin Enlaces Personalizados: Solo se reconocen URLs directas como https://sitio.com.
  • 🚫 Sin Fórmulas ni Diagramas: Se recomienda exportar como imagen o texto enriquecido.
  • Botón Copiar para WhatsApp: Adapta el texto y lo copia directo al portapapeles.
Telegram MarkdownV2

Soporta spoilers ||texto||, subrayado __texto__ y citas expandibles **>. Requiere escapar 18 caracteres especiales.

  • Spoilers difuminados interactivos

Slack mrkdwn

Usa negrita con asterisco simple *negrita*, tilde para tachado ~tachado~ y enlaces tipo <url|Nombre>.

  • Citas globales >>>
  • Sin resaltado de sintaxis
Reddit Snoo-Flavored

Incluye superíndices con exponente x^2 o ^(frase) y spoilers exclusivos con corchete >!spoiler!<.

  • Tablas completas GFM
  • Spoilers >!secreto!<
Obsidian / PKM Wikilinks Extended

Redes neuronales de notas con enlaces bidireccionales [[Nota]], transclusiones ![[Imagen]] y tags #tag.

  • KaTeX y Mermaid 100% compatibles
  • Callouts plegables > [!NOTE]-
Notion Block Markdown

Markdown convertido a bloques interactivos. Soporta toggle lists con > Toggle, fórmulas LaTeX y bases de datos.

  • Listas desplegables interactivas
  • Ecuaciones en bloque $$...$$
Jira / Confluence Atlassian Markup

Sintaxis wiki con subrayado +texto+, tachado -texto-, superíndice ^texto^ y paneles {code}.

  • Paneles de advertencia {panel}
  • Citas de autor {quote}

  • Tab : Sangría / Indentar 2 espacios
  • Shift + Tab : Reducir sangría
  • Enter : Continuar viñetas o tareas automáticamente

Navegación & Vistas

  • Ctrl + K : Paleta de comandos rápidos
  • Ctrl + F : Buscar y reemplazar
  • Ctrl + N : Nuevo documento en blanco
  • Ctrl + S : Guardar checkpoint manual
  • Ctrl + \ : Mostrar / Ocultar panel lateral
  • F11 : Modo Zen de máxima concentración
  • Esc : Cerrar cualquier modal o buscador activo
